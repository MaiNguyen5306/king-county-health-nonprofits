# Financial Resilience of King County Community Health Nonprofits

## Project Goal

Analyze the financial capacity and resilience of community-health nonprofits headquartered in King County, Washington, from tax years 2019–2023.

## Core Research Question

How do funding mix, program-spending allocation, and financial stability differ across community-health nonprofit service types and organization sizes?

## Planned Population

- King County–headquartered organizations
- Tax-exempt 501(c)(3) organizations
- Full Form 990 filers
- Tax years 2019–2023
- Health-related organizations such as:
  - Community clinics
  - Mental-health organizations
  - Disability-service organizations
  - Health education and public-health organizations
  - Disease support and medical research organizations

## Planned Analysis

- Revenue and expense trends
- Funding-source mix
- Operating margins
- Program-expense share
- Liabilities-to-assets ratio
- Revenue growth and volatility
- Financial comparisons by health subsector and organization size

## Planned Tools

- Python
- ProPublica Nonprofit Explorer API
- IRS nonprofit datasets
- MySQL
- Excel
- Tableau
- Git and GitHub

## Important Analytical Boundary

This project evaluates organizational financial capacity and resilience. It does not measure healthcare quality, patient outcomes, or organizational effectiveness.
